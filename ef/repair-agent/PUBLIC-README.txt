COUNCIL LOCAL REPAIR AGENT

Extract this whole download on the Windows PC that runs Council.
Double-click START-COUNCIL-AGENT.cmd.
Sign in to ChatGPT and complete normal local-agent permission setup if prompted.
Keep the agent window open while it works.

The launcher installs official OpenAI Codex CLI 0.160.1 in the user's profile
using existing Node.js. The agent performs the Windows work itself. It receives
the prepared fixes, evidence, backup requirements and live acceptance mission.
Normal security or permission prompts can still require a decision.

Run the same launcher again after an interruption: it reads its saved progress.
Do not run individual candidate scripts blindly. The agent must compare them
with the installed application, preserve data and verify a rollback first.

Startup launches the Council supervisor. The coding agent runs when launched.
The planned desktop Recover Council action recovers Council processes while
preserving saved work; interrupted actions are not replayed.

This download is a tested repair-agent package, not a claim that the installed
Council has been fixed. Actual fresh launch, installed model/tools, original
data, Bitdefender, reboot and 65-minute idle/resume remain local checks.
Keep Bitdefender enabled; this package does not disable it or add exclusions.

Private earlier handoffs should be supplied locally to the agent, not uploaded
to the public repository. ACCEPTANCE.json identifies the tested source and run.
